# FFmpeg Binaries Directory

This directory contains the 64-bit Windows FFmpeg and FFprobe binaries used by King Video Cutter:
- `ffmpeg.exe`
- `ffprobe.exe`

These binaries can be downloaded from official FFmpeg builds (e.g. https://www.gyan.dev/ffmpeg/builds/ or https://github.com/BtbN/FFmpeg-Builds/releases).
